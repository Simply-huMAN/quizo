# Quizo
A simple and flexible tool designed to create quizzes from any user-provided topic.

### ✨ Key Features
- **Topic-based quiz generation**  
  Enter any topic and instantly generate a quiz tailored to it.
- **Flexible question count**  
  Generate a random set of **2–4 questions**, or specify an exact number of questions you want.
- **Single-choice multiple-option questions**  
  All questions are presented as single-choice, multiple-option format for clarity and ease of use.
- **Answer review after submission**  
  Users can review their selected answers after submitting the quiz, enabling quick self-assessment.
